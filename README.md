# sshf
A **simple**, **lightweight**, and **informative** TUI for SSH

[![demonstration](https://i.imgur.com/UN9911a.gif)](https://asciinema.org/a/pE8Bn78ap42mnYKP)

## How does it work?
The application uses the `~/.ssh/config` file to generate a list of hosts and connect to them

## Installation
1. Download `sshf-{VERSION}-{SYSTEM_NAME}-${SYSTEM_PROCESSOR}.tbz` from [releases](https://github.com/stith76/sshf/releases) and unpack them
2. Install
- Run
  ```bash
  ./install.sh
  ```
  inside the folder
3. Run
```bash
sshf
```
## Uninstall
- Run
  ```bash
  ./uninstall.sh
  ```
  inside the folder
